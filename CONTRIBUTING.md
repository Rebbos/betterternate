# Contributing to Better Ternate

Thanks for helping! Full guide arrives in Phase 9. For now:

1. Fork, then branch from `main` (`fix/...`, `feat/...`, `content/...`).
2. `npm install`, then `npm run dev`.
3. Before opening a PR: `npm run lint && npm run typecheck && npm test`.
4. Content lives in `/content`. Never add real names or contact details; use the
   "John Doe" placeholders described in `CLAUDE.md` and keep `"sample": true`.
5. Found wrong info but don't code? Open a **Data correction** issue.
